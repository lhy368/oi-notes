## 🔍 逐题分析

### A. Divisible Array ✅

**题意**：构造一个长度为 n 的数组，每个元素不同，且 a_i 能被 i 整除，且数组值尽量小。

**思路**：直接输出 2, 4, 6, ..., 2n。每个 a_i = 2i 能被 i 整除，且值不重复。

**评价**：签到题，2min 稳过 ✅

---

### B. Permutation Swap ✅ (+1)

**题意**：给排列 p，你可以选一个 k，然后可以交换任意 p_i 和 p_j 当 |i-j| = k。问最大的 k 使得能通过交换将排列排好序。

**思路**：对于每个不在正确位置的 p_i，需要的距离 |p_i - i| 必须是 k 的倍数。所以 k 必须是所有这样的距离的公约数。求 GCD 即可。

**+1 原因**：小细节失误（可能是 INF 初始化或边界）。

**评价**：思路正确，+1 可接受 ✅

---

### C. Counting Orders ✅

**题意**：给两个数组 a, b。问 a 有多少种排列使得对所有 i，a_i > b_i。

**思路**：排序 a 和 b。对每个 a_i（从小到大），二分找 b 中有多少个比它小，减去前面已分配的数量，乘法原理累乘。

**评价**：40min AC，排序+二分+组合计数的组合拳打得不错 ✅

### D1. Range Sorting (Easy Version) ❌ 未提交

**题意**：给定数组 a，定义 f(l, r) = 将 a[l..r] 排序的最小操作次数。每次操作可选任意连续子段排序。求所有 f(l, r) 之和。n ≤ 5000。

**核心结论**：

> f(l, r) 的最小操作数 = 不能「自然分割」的位置数 + 1
>
> 一个位置 i 能自然分割 当且仅当 max(a[l..i]) < min(a[i+1..r])
>
> 等价于：f(l, r) = (r - l + 1) - (满足分割条件的 i 的数量)

**O(n²) 做法**：

```
枚举左端点 l:
  维护一个块列表 blocks，每块记录 [mn, mx]
  对 r = l..n:
    把 a[r] 作为新块 [a[r], a[r]]
    从后往前合并：while 前一块.mx > 当前块.mn → 合并
    合并后 f(l, r) = 当前块数 - 1
    ans += f(l, r)
```

另一种更简单的 O(n²)：

```
枚举 l:
  mn = INF, mx = -INF, 维护当前"段"的 mn/mx
  对 r = l..n:
    更新 mn, mx
    // 往前找分割点
    ...
```

**你卡在哪**：你开了个单调栈的头就方向偏了。这道题的核心是 **区间最值维护 + 块合并**，不是单调栈。

**补题建议**：
- 知识点：区间最值 DP / 贡献法
- 预计用时：30-45min
